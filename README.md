# 💱 Currency Converter Tool

A simple and responsive **Currency Converter Tool** built using **HTML, CSS, and JavaScript**. It allows users to convert amounts between different currencies using exchange-rate data and keeps a history of recent conversions.

## 📌 Project Overview

This project provides an easy-to-use interface for converting currencies. Users can select the currencies, enter an amount, and instantly view the converted value.

## ✨ Features

* 💰 Convert between multiple currencies
* 🌍 Support for different international currencies
* 🚩 Currency flags
* 📜 Conversion history
* 💾 Stores history using LocalStorage
* 📱 Responsive design
* 🔄 Exchange rates through an API

## 🛠️ Technologies Used

* **HTML5** – Structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Functionality and API handling
* **Currency Exchange API** – Exchange-rate data
* **LocalStorage** – Saving conversion history

## ⚙️ How It Works

1. Enter the amount you want to convert.
2. Select the **From** currency.
3. Select the **To** currency.
4. Click the **Convert** button.
5. The application fetches the exchange rate and displays the converted amount.
6. The conversion is added to the history.

The application stores the **latest 10 conversions** using LocalStorage.

Example:

```text
100 USD → INR = ₹8350
500 EUR → USD = $540
```

## 🚀 How to Run

1. Download or open the project folder.
2. Open it in **VS Code**.
3. Open `index.html` using **Live Server**.
4. Start converting currencies.
